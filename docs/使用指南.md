#### 模型下载
完成设置后检查网络连接进行模型下载，点击左侧下方图标`设置`，进入`模型设置`界面。
<br>

![](../../data/images/intro/模型管理.png)

网络检索和知识库功能都需要本地Ollama嵌入模型的支持，请点击Ollama模型根据步骤进行ollama模型的下载。


#### 🔽 下载 & 安装 Ollama
- 访问 [Ollama 官网](https://ollama.com/download) 下载并安装
- 安装完成后，运行以下命令检查是否安装成功：
  ```sh
  ollama --version
  ```
  若显示版本信息，则表示安装成功 ✅

#### 📥 下载 & 部署 DeepSeek-R1 模型
 **建议**：如果 PC 硬件资源有限，建议下载小参数量模型

- 在终端中输入以下命令下载并运行模型：
  ```sh
  ollama run deepseek-r1:1.5b
  ```
- 其他 DeepSeek-R1 模型下载方式：
  ```sh
  ollama run deepseek-r1:7b   # 7B 版本
  ollama run deepseek-r1:8b   # 8B 版本
  ollama run deepseek-r1:14b  # 14B 服务器端
  ollama run deepseek-r1:32b  # 32B 服务器端
  ollama run deepseek-r1:70b  # 70B 服务器端
  ```
- 更多模型可参考：[Ollama Library](https://ollama.com/library)
- **模型下载时间** 与 **参数量** 成正比，请耐心等待 ☕
- **模型生成速度** 与 **参数量** 成反比，请选择合适的模型 🏎

✅ **当终端显示 `success`，表示模型已准备就绪**

![](../../data/images/intro/ollama1.png)


**注意：**
* 如果显示下载失败，可能由于网络中断导致，恢复网络连接后，可自行恢复下载；
* 大模型下载速度取决于当前的网络状况，由于每个模型文件较大，需要耐心等待下载。

## 🤖 一、智能体功能操作指南

OpenChat v1.0.2 引入了 **智能体系统（Agent System）**，用户可自定义专属智能体或快速启用预制助手，提升个性化使用体验。

### 1. 新建自定义智能体

1. 点击左侧导航栏的【智能体】模块
2. 点击右上角的【新建】按钮，进入创建页面
3. 填写以下信息：
   - 名称：给你的智能体起一个名字
   - 分类：选择或创建一个类别
   - 系统提示词：输入 agent 的角色或行为设定
   - 标签（可选）：为 agent 添加搜索关键词

4. 填写完成后，点击【保存】按钮即可完成智能体的创建

📷 示例页面如下：  
![](../../data/images/intro/agent_create.png)

---

### 2. 启用预制智能体助手

1. 点击左侧【智能体】模块
2. 在中间栏区域可查看不同分类的预制的智能体助手
3. 点击想要使用的助手卡片（如编程助手、学习助手等）
4. 系统将自动配置提示词，并进入与该智能体的专属对话页面

📷 示例预制助手界面：  
![](../../data/images/intro/trained_agent.png)

---

### 3. 智能体对话与管理

- 每个智能体都有专属对话空间，支持：
  - 模型切换
  - 历史记录查看
  - 设置独立上下文开关
- 用户可通过标签快速筛选已有智能体，并进行修改或删除操作

📷 智能体对话窗口示例：  
![](../../data/images/intro/agent_talk.png)

## 🌍 二、沉浸式翻译功能操作指南

OpenChat v1.0.2 提供了全新的 **沉浸式翻译功能**，支持多语言文本和文档互译，界面友好，交互便捷。

### 1. 进入 AI 翻译页面

- 点击侧边栏的【翻译】入口，进入翻译主界面并选择原始和目标语言

---

### 2. 文件翻译操作流程

1. 在首页中，点击翻译功能进入翻译，再点击文档翻译进入文档翻译页面。
2. 点击左侧【上传文件】按钮，选择 PDF/DOCX/TXT 文件
3. 文件上传后会出现在下方“文件翻译历史”列表中，显示状态与预览
4. 点击某个文件卡片，可预览其原始内容
5. 点击【立即翻译】按钮，系统将自动执行语言识别与翻译操作
6. 翻译完成后，右侧区域将展示对应的译文内容

📷 翻译界面整体布局：  
![](../../data/images/intro/trans_page.png)


---

### 3. 页面同步与视图控制

📷 文件翻译界面：  
![](../../data/images/intro/trans_file.png)

翻译完成后支持以下辅助操作：

- ✅ **同步滚动**：开启后，原文与译文将一同滚动，便于比对
- ✅ **仅译文展示**：隐藏原文，仅保留翻译内容，适合清晰查看译文

 


---

### 4. 文本翻译模块操作

- 在首页中，点击翻译功能进入翻译，进入文本翻译界面
- 位于右侧页面，可直接输入或粘贴要翻译的内容
- 支持中文、英文、日文、法文、韩文等互译
- 配套功能：
  - **术语表配置**：用于设定专属词汇翻译规则
  - **翻译历史**：查看过往翻译记录，便于复用



## ⚙️ 三、自动更新功能

OpenChat 现已支持客户端自动更新，用户无需手动下载安装新版本。

📷 自动更新提示界面如下：  
![](../../data/images/intro/auto_update.png)


### 操作说明：

- 当检测到新版本时，欢迎页面会弹出更新提示：
  - 显示版本号、更新时间与更新内容
  - 提供【立即更新】与【稍后再说】两个选项

- 点击【立即更新】后将自动：
  1. 下载新版本
  2. 安装替换旧程序
  3. 自动重新启动程序（⚠️ Mac系统会弹出权限提示，需用户授权执行）

## 3.升级功能
### 3.1 提升知识库能力
本次升级，知识库新支持了多种文档类型，在新建知识库，上传文件时可以看到全部的支持的类型，其中，`PDF支持影印版上传，但是不支持纯图片类型的docx上传`。如果纯图片类型的docx文档，需保存为PDF格式再进行上传。

### 3.2 增强网络检索能力
本次更新，增强了网络检索能力，支持了bing检索，可以选择Serper和bing两种方式中任意一种进行检索增强，同时修复了bing检索存在的问题。
其中，Serper检索方式，需要准备搜索引擎服务Serper的API Key，通过`https://serpapi.com/`注册获取。

### 3.3 对话分组 | 重新生成 | 对话内容删除 
#### 3.3.1 对话分组
本版本，将对话，按照时间进行了分组，分为今天、最近3天、最近7天、最近30天、更早等组别，供用户进行方便查看，其中，可能有别个组别不存在，是用户在期间未进行过对话的原因导致。
#### 3.3.2 对话重新生成

![](../../data/images/intro/对话重新生成1.jpg)
新增对话重新生成功能，针对当前对话结果，如果用户不满意，可以重新生成对话，系统将重新生成对话结果；
重新生成的结果与前一次的结果同时存在，用户可以切换查看不同结果内容；
对话的历史记录中，如果存在不同结果，也会显示多个结果，可切换，供用户查看；

#### 3.7.3 对话内容删除

![](../../data/images/intro/对话重新生成2.jpg)


如果用户针对某次会话，觉得不满意，或者不想让其在对话历史中显示，可以将对话内容进行删除，删除后将不可见，也无法恢复。
