# 关于 OpenChat 安全性与MacOS系统设置说明

感谢您使用 **OpenChat**！

OpenChat 是一款开源、可本地部署的 AI 桌面应用，旨在为开发者与专业用户提供一个 **安全、自由、可控的 AI 平台**。

---

## 🔐 我们重视您的隐私与数据安全

- ✅ **开源透明**：您可在 GitHub 仓库中完整查看和验证源代码  
- ✅ **离线运行**：OpenChat **不会联网收集任何信息**，无任何埋点、无云端同步  
- ✅ **数据本地保存**：所有聊天记录、设置与模型调用仅存在于本地，您完全拥有数据控制权

## ❗ 为什么 macOS 会提示“无法打开”或“文件已损坏”？

由于 OpenChat 是通过开发者团队自行构建与打包（未经过 App Store 官方认证），macOS 安全机制（Gatekeeper）可能会在首次运行时提示：

- “无法打开 OpenChatInstall，因为无法验证开发者身份”
- “文件已损坏，建议将其移到废纸篓”
- “来自身份不明开发者的 App”

这并不代表软件有风险，而是 macOS 对所有未签名 App 的默认防护行为。

---

## ✅ 如何解决：开启“任何来源”选项

<br>

1. 打开【系统设置】或【系统偏好设置】
2. 点击【安全性与隐私】 > 下拉至最下方找到【安全性】
3. 在下方找到 **“允许从以下位置下载的应用程序”**
4. 选择 ✅ “任何来源”

<br>

如果您没有看到 **任何来源** 选项，说明其被Mac系统隐藏，我们建议您按照以下步骤开启 macOS 的“任何来源”选项，以便正常运行：


### 📦 第一步：打开终端（Terminal）

打开 Launchpad → 其他 → **终端**（或按 `⌘ + 空格` 输入“终端”）

### 📋 第二步：输入以下命令并按下回车

```bash
sudo spctl --master-disable
```

系统将提示输入密码（输入时不会显示），输入您的**Mac 登录密码**后回车。

### 🧭 第三步：启用“任何来源”选项

此时 **任何来源** 选项应已出现在【系统设置】>【安全性与隐私】 >【安全性】> **“允许从以下位置下载的应用程序”** 选项下，勾选 **”任何来源“** 即可。

> 如果没有看到该选项，请重启一次电脑，系统会自动刷新该设置。


---

## 🔐 可选：恢复默认限制

若您在安装 OpenChat 后希望恢复默认限制，只需在终端执行：

```bash
sudo spctl --master-enable
```

“任何来源”选项将自动隐藏，macOS 将恢复最严格的验证策略。
