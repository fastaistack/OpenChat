# OpenChat - Your All-in-One AI Platform

---

OpenChat is a client application that provides an interactive conversational interface based on large language models (LLMs). It enables users to easily access various AI models for knowledge Q&A, online information retrieval, knowledge base interaction, and document dialogue.

Here you can download the official OpenChat client packages for multiple platforms. We recommend using the official version for the best experience and access to the latest features. OpenChat does **not** collect any personal information; all chat logs and uploaded files are stored locally. The source code is open-sourced under the **MIT License**.

If you encounter macOS security warnings like **“cannot open because it is from an unidentified developer”** or **“file is damaged and should be moved to Trash”**, please refer to the *MacOS Security Bypass Guide* on the left panel. Follow the simple steps once to run OpenChat normally.

### 📝 Release Notes

#### OpenChat Deepseek-OCR (Beta)

> Release Date: October 24, 2025
> Version Code: Deepseek-OCR

A beta version built upon v1.0.4, introducing **DeepSeek-OCR** for testing and experience:

1. **Upload Image**: Use the upload box to import an image.
2. **Select Task Type**:

   * Free OCR: Extract raw text.
   * Convert to Markdown: Retain structure.
   * Parse Charts: Extract structured data.
   * Image Description: Generate detailed captions.
3. **Process OCR**: Click to process and view results on the right panel.

#### OpenChat v1.0.4

> Release Date: August 1, 2025
> Version Code: v1.0.4

This update focuses on practicality and ecosystem expansion. It introduces **Kimi-k2**, **Step-2**, **OpenRouter**, and **Volcano Engine**, enhancing multi-instance management with **Server Deployment Cloning** and **Custom Cache Directory**. PDF translation, UI fluidity, and text selection were optimized for a smoother experience.

For macOS users facing update issues, please manually open the downloaded file at:

`/Users/<your-username>/openchat/download/Openchat.dmg`

Then double-click **OpenchatV1.0.4Updater** to update manually.

Create and manage your own AI Agents:

* Custom name, category, behavior, and system prompt.

Supports five languages (EN/CH/JP/KR/FR) and multiple file types (PDF/DOCX/TXT):

* Dual-panel view: Original vs Translated.
* Translation history and glossary management.
* Smooth synchronized scrolling.

#### 🔄 Auto Update

* Background update checks at launch.
* Popup with version info.
* One-click update process with auto restart.

### 🛠 Other Improvements

* Agent and Translation modules now support state persistence.
* Fixed multi-platform model switching issues.
* Improved multilingual UI and performance.

## 💻 Configuration & Usage

### 1. System Requirements

* Memory: 8GB or higher
* OS: Windows 10/11 (64-bit) & macOS 12.5+ (Intel/Apple Silicon)

### 2. Installation

#### Step 1: Download OpenChat Installer

* This guide provides download, setup, and usage instructions.
* Windows: `OpenChatSetup.exe`
* macOS: `OpenChat.dmg`

#### Step 2: Installation

* Double-click the installer and accept the agreement.
* Choose a custom installation path.
* For macOS: drag `OpenChat.app` into Applications. If security warnings appear, approve and reopen from *System Preferences > Security*.

### 3. Usage

Refer to the **User Guide** on the left panel for detailed configuration and feature explanations.
