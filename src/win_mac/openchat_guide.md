# OpenChat 使用指南

OpenChat 是一款本地化 AI 聊天程序，支持云端与本地大模型、插件扩展、知识库检索、沉浸式翻译及智能体系统。下文概述主要功能与操作流程。

---

## 1. 客户端配置与模型接入

### 1.1 申请并配置 API
1. 进入左下 **设置 → 模型管理**  
2. 点击 *“点击获取”* 跳转各平台申请 API Key（支持 OpenAI、DeepSeek、百度千帆、腾讯云、Kimi、智谱等）  
3. 在对应卡片粘贴 Key，点击 **保存**

### 1.2 本地模型（Ollama）
1. 安装 Ollama：<https://ollama.com/download>  
2. 终端运行
   ```bash
   ollama run deepseek-r1:1.5b
   ```
   出现 *success* 即本地模型可用。可换 `:7b`、`:14b` 等版本。

### 1.3 服务器自部署（可选）
填写远程 **URL + API Key** 接入自建模型服务。

---

## 2. 对话
在聊天界面右上选择模型即可提问。支持历史分组、重新生成回答、删除记录。

---

## 3. 插件系统
在输入框上方可启用单一插件：

| 插件 | 作用 |
| ---- | ---- |
| 敏感词检测 | 过滤不当内容 |
| 网络检索   | 联网补充信息 |
| 知识库检索 | 关联私有文档 |
| 文档问答   | 针对上传文件问答 |

在设置 - 参数设置填写参数（嵌入模型、阈值等）并保存（详见步骤7）。

---

## 4. 知识库
1. 侧栏 **知识库** → **新建**（名称须英文）  
2. 上传 PDF / DOCX / TXT 等文件并解析  
3. 聊天界面启用“知识库检索”插件，选择知识库即可查询

---

## 5. 智能体
1. 侧栏 **智能体** → **新建**，填写名称、系统提示等  
2. 或直接启用预置助手  
3. 智能体拥有独立对话历史，可编辑或删除

---

## 6. 沉浸式翻译
1. 在 **翻译** 页面可访问文本/文档翻译
2. 在文件翻译页面上传文件 → 点击 **立即翻译**  
3. 可对翻译后文本/文档进行导出
4. 支持同步滚动、仅译文视图及术语表。

---

## 7. 全局设置功能

在“设置 - 参数设置”中，您可以对以下插件进行全局参数配置：

- **模型参数**：设置所有模型通用的默认参数（如温度、最大长度等）。
- **网络检索**：配置是否启用网络检索插件，并设置相关接口参数。
- **敏感词检测**：可配置是否启用敏感词检测插件及其检测规则。

这些设置将应用于所有相关模型和功能，有助于统一控制和行为规范。

---

## 8. 自动更新
新版本发布时将弹窗提示，可一键下载并自动重启。
