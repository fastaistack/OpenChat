# 📦 OpenChat v1.0.4 Changelog

### ✨ New Features

* Added support for new models: **Kimi-k2** and **Step-2**
* New platform integrations:

  * Support for **OpenRouter**
  * Support for **Volcengine**
* More platforms now support **custom model integration**, including OpenRouter, Jina, and Baichuan
* Support for **custom file cache directory**, offering more flexible cache control
* Introduced **server deployment cloning**, allowing one-click duplication of deployment configurations for easier multi-instance management

### 🛠️ Improvements

* **Optimized PDF translation output**, improving layout and rendering
* **Enhanced text selection in conversations**, making copying more convenient
* **Improved model list behavior**: you can now click "Model Settings" directly from the dropdown list to configure the selected model

---

### ⚠️ macOS Manual Update Notice

We’ve noticed that some macOS users may encounter issues with the online update in version v1.0.3:

> After downloading the update and clicking “Restart Now,” it may still prompt for an update. This means the update did not complete successfully.

Please **do not click the update repeatedly**, as it may waste your time. You can update manually as follows:

#### Manual Update Path:

![](../../data/images/intro/手动更新.png)

```
Finder → YourUsername/openchat/download/Openchat.dmg
```

After opening the `.dmg`, double-click to run:

```
OpenchatV1.0.4Updater
```

![](../../data/images/intro/更新完成.png)

This will complete the manual update process.
